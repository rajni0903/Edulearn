EduLearn — Online Learning Management System

EduLearn is a modern, fully responsive Online Learning Management System (LMS) built with React.js. It supports three user roles — Student, Instructor, and Admin — each with their own dedicated dashboard and features.



🌐 Live Website

> Access the platform from any device — mobile, tablet, or desktop. The interface automatically adjusts to your screen size.



👥 User Roles

| Role | Access |
||--|
| Student | Browse courses, watch videos, submit assignments, give quizzes |
| Instructor | Create & manage courses, upload videos, create assignments & quizzes |
| Admin | Full control — manage users, courses, categories, enrollments, analytics |



✨ Features — Student

- Dashboard Overview — See enrolled courses, completion progress, quiz results at a glance
- My Courses — View all enrolled courses with progress percentage
- Course Videos — Watch video lessons, mark videos as complete, track progress
- Assignments — View and submit assignments for enrolled courses
- Practice Quizzes — Attempt multiple choice quizzes with instant result
- Final Exam — Take the final exam for a course
- Certificates — Download completion certificate (PDF) after finishing a course
- My Profile — View and update personal profile information



✨ Features — Instructor

- Dashboard Overview — See total courses, students enrolled, revenue stats
- My Courses — View and manage all created courses
- Create Course — Add new courses with title, description, category, price, thumbnail
- Manage Videos — Upload and manage YouTube video lessons for each course
- Create Assignments — Add assignments with due dates for students
- Student Submissions — View and grade student assignment submissions
- Manage Quizzes — Create multiple choice quizzes with correct answers
- Analytics — View course performance and student engagement data
- My Profile — Update bio and personal information



✨ Features — Admin

- Dashboard Overview — Total users, courses, enrollments, pending approvals at a glance
- Manage Users — View, create, update, activate/deactivate all users
- Instructor Approvals — Approve or reject instructor registration requests
- Manage Courses — View and delete any course on the platform
- Categories — Create and manage course categories
- Manage Quizzes — View and edit all quizzes across the platform
- Assignments — View and manage all assignments
- Enrollments — View all student-course enrollments
- Analytics — Platform-wide statistics and growth data



📱 Responsive Design

- Works perfectly on mobile phones, tablets, and laptops
- Sidebar navigation on desktop; hamburger menu (☰) on mobile
- All dashboards, tables, and forms are fully mobile-friendly



🔐 Authentication

- Secure JWT-based login system
- Role-based access — each user sees only their own dashboard
- Instructor registration requires Admin approval before login



🛠️ Tech Stack — Frontend

| Technology | Purpose |
|--||
| React.js | UI framework |
| React Router | Page navigation |
| Axios | API calls to backend |
| Bootstrap 5 | Responsive layout |
| Bootstrap Icons | Icons throughout the app |
| React Toastify | Success/error notifications |
| Google Fonts | Poppins + Playfair Display |





EduLearn — ऑनलाइन लर्निंग मैनेजमेंट सिस्टम

EduLearn एक आधुनिक और पूरी तरह से Responsive Online Learning Platform है जो React.js से बना है। इसमें तीन तरह के users होते हैं — Student, Instructor, और Admin — और हर किसी का अपना अलग Dashboard और Features हैं।



🌐 Live Website

> यह website मोबाइल, टैबलेट, और लैपटॉप — सभी devices पर सही से काम करती है। Screen size के हिसाब से layout अपने आप बदल जाता है।



👥 User Roles (यूज़र की भूमिकाएं)

| Role | क्या कर सकते हैं |
||--|
| Student | Courses देखो, Videos देखो, Assignments submit करो, Quiz दो |
| Instructor | Courses बनाओ, Videos upload करो, Assignments और Quizzes बनाओ |
| Admin | पूरा control — Users, Courses, Categories, Enrollments सब manage करो |



✨ Student के Features

- Dashboard Overview — Enrolled courses, progress, quiz results एक नज़र में देखो
- My Courses — सभी enrolled courses और उनकी progress percentage देखो
- Course Videos — Video lessons देखो, complete mark करो, progress track करो
- Assignments — Enrolled courses के assignments देखो और submit करो
- Practice Quizzes — Multiple choice quizzes दो और तुरंत result देखो
- Final Exam — Course का final exam दो
- Certificates — Course पूरा होने पर PDF Certificate download करो
- My Profile — अपनी profile देखो और update करो



✨ Instructor के Features

- Dashboard Overview — Total courses, enrolled students, stats एक नज़र में
- My Courses — अपने सभी बनाए हुए courses देखो और manage करो
- Create Course — नया course बनाओ — title, description, category, price, thumbnail के साथ
- Manage Videos — हर course के लिए YouTube video lessons upload और manage करो
- Create Assignments — Students के लिए assignments बनाओ due date के साथ
- Student Submissions — Students के submitted assignments देखो और grade करो
- Manage Quizzes — Multiple choice quizzes बनाओ सही जवाब के साथ
- Analytics — Course performance और student engagement data देखो
- My Profile — Bio और personal information update करो



✨ Admin के Features

- Dashboard Overview — Total users, courses, enrollments, pending approvals एक जगह
- Manage Users — सभी users को देखो, बनाओ, update करो, activate/deactivate करो
- Instructor Approvals — Instructor registration requests को approve या reject करो
- Manage Courses — Platform पर कोई भी course देखो और delete करो
- Categories — Course categories बनाओ और manage करो
- Manage Quizzes — Platform के सभी quizzes देखो और edit करो
- Assignments — सभी assignments देखो और manage करो
- Enrollments — सभी student-course enrollments देखो
- Analytics — पूरे platform की statistics और growth data देखो



📱 Responsive Design (मोबाइल फ्रेंडली)

- मोबाइल, टैबलेट, और लैपटॉप — सभी पर perfect काम करता है
- Desktop पर sidebar navigation; Mobile पर hamburger menu (☰)
- सभी dashboards, tables, और forms mobile पर सही से दिखते हैं



🔐 Login System (लॉगिन सिस्टम)

- Secure JWT-based login system
- हर user सिर्फ अपना dashboard देख सकता है
- Instructor registration के बाद Admin की approval ज़रूरी है login के लिए
